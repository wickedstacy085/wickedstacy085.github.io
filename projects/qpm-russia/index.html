Аннотация. Как повышение ключевой ставки и ослабление рубля передаются в инфляцию и выпуск в России? Я собрала малую полуструктурную модель (QPM) по образцу МВФ из четырёх уравнений, откалибровала её и решила с рациональными ожиданиями. Данные — Росстат, BIS и FRED за II кв. 2011 – II кв. 2026. Неожиданное повышение ставки на 1 п.п. снижает квартальную инфляцию максимум на 0,37 п.п. через 3 кв., выпуск — на 0,23%. Ослабление рубля на 10% повышает инфляцию на 3,2 п.п. через 2 кв. Параметры модели откалиброваны, а не оценены, поэтому это иллюстрация механизма, а не прогноз.

Модель

Все переменные — отклонения от равновесия, в процентах; инфляция и ставки — в годовом выражении.

\[ \begin{aligned} \text{IS:}\quad & \hat y_t = b_{lead}\,\hat y_{t+1} + b_{lag}\,\hat y_{t-1} - b_{rmci}\left[b_{rr}\,\hat r_t - (1-b_{rr})\,\hat z_t\right] + \varepsilon^y_t \\ \text{Филлипс:}\quad & \hat\pi_t = a_{lead}\,\hat\pi_{t+1} + (1-a_{lead})\,\hat\pi_{t-1} + a_{rmc}\left[a_y\,\hat y_t + (1-a_y)\,\hat z_t\right] + \varepsilon^\pi_t \\ \text{Ставка:}\quad & \hat\imath_t = g_{lag}\,\hat\imath_{t-1} + (1-g_{lag})\left[(1+g_\pi)\,\hat\pi_{t+1} + g_y\,\hat y_t\right] + \varepsilon^i_t \\ \text{UIP:}\quad & \hat z_t = e_{lead}\,\hat z_{t+1} + (1-e_{lead})\,\hat z_{t-1} - \hat r_t/4 + \varepsilon^z_t \\ \text{Фишер:}\quad & \hat r_t = \hat\imath_t - \hat\pi_{t+1} \end{aligned} \]

\(\hat y\) — разрыв выпуска, \(\hat\pi\) — отклонение квартальной инфляции (SAAR) от цели 4%, \(\hat\imath\) — отклонение ключевой ставки от нейтральной, \(\hat r\) — разрыв реальной ставки, \(\hat z\) — разрыв реального курса (рост — ослабление рубля). Модель решается итерацией матрицы решения \(x_t = P x_{t-1} + Q\varepsilon_t\) (Binder, Pesaran 1995); решение проверяется по невязке и спектральному радиусу \(P\).

Почему здесь нет прогноза

Если запустить модель из гэпов II кв. 2026 без новых шоков, ключевая ставка опускается до 2,3% через 5 кв., а квартальная инфляция — до 0,9%. Это неправдоподобно, и причины видны:

  • реальный курс на конце выборки — HP-гэп −13,3%, а у HP-фильтра концы ряда ненадёжны;
  • нейтральная ставка задана допущением, а не оценена;
  • в модели нет инфляционных ожиданий, бюджета и нефти, которые сейчас поддерживают инфляцию.

Прогноз появится после оценки гэпов фильтром Калмана вместе с моделью.

Записка

  • Текущее состояние (II кв. 2026): разрыв выпуска −0,75%, инфляция 5,5% г/г, реальная ставка выше нейтральной (по допущению) на 5,9 п.п., рубль крепче равновесия на 13,3%.
  • Повышение ставки сильнее всего снижает инфляцию через 3 кв.; решения, принятые сегодня, отражаются в инфляции в основном через полгода–год.
  • Курсовой канал быстрый: ослабление рубля переходит в инфляцию за 2 кв.
  • Главный риск выводов — калибровка: при другом весе курса (\(b_{rr}\), \(a_y\)) соотношение каналов меняется.

Ограничения и что дальше

  • Параметры откалиброваны, а не оценены. Следующий шаг — байесовская оценка или фильтр Калмана.
  • Гэпы получены HP-фильтром, на конце выборки он ненадёжен; в QPM их обычно оценивают фильтром Калмана вместе с моделью.
  • Нейтральная ставка постоянна и задана допущением.
  • В модели нет нефти, бюджетного правила и внешнего спроса — ключевых для России каналов.

```{python}
#| label: setup

import sys
sys.path.insert(0, "py")
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import qpm

plt.rcParams.update({"figure.dpi": 110, "axes.spines.top": False, "axes.spines.right": False,
                     "axes.grid": True, "grid.alpha": .3, "font.size": 10})
p = qpm.Params()
P, Q, info = qpm.solve(p)
df = qpm.load_data()
g = qpm.build_gaps(df)
last = g.index[-1]
irf_i = qpm.irf(p, "e_i", 1.0, 16)
irf_z = qpm.irf(p, "e_z", 10.0, 16)
x0 = g.loc[last, qpm.VARS].to_numpy(float)
path = qpm.simulate_from(p, x0, 8)
path.index = pd.period_range(last + 1, periods=8, freq="Q")

def fmt(x, d=1):
    return f"{x:.{d}f}".replace(".", ",").replace("-", "−")

def q(per):
    return f"{['I', 'II', 'III', 'IV'][per.quarter - 1]} кв. {per.year}"

pi_min = irf_i["pi"].min(); pi_min_t = int(irf_i["pi"].idxmin())
y_min = irf_i["y"].min()
pi_z_max = irf_z["pi"].max(); pi_z_t = int(irf_z["pi"].idxmax())
infl_end = path["pi"].iloc[-1] + qpm.TARGET
rate_end = path["i"].iloc[-1] + qpm.R_NEUTRAL + qpm.TARGET
```
