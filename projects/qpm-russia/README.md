# README: «Малая QPM-модель российской экономики» (Анастасия Смирнова)

## Обзор

Полуструктурная модель из четырёх уравнений (IS, кривая Филлипса, правило ставки, UIP) по образцу
Berg, Karam, Laxton (2006), IMF WP/06/80. Параметры откалиброваны, модель решается с рациональными
ожиданиями. Один файл, `index.qmd`, строит все таблицы и рисунки страницы
https://wickedstacy085.github.io/projects/qpm-russia/. 

## Данные

| Ряд | Источник | Код |
|---|---|---|
| ВВП, млрд руб. в ценах 2021 г., SA | Росстат | `VVP_kvartal_s-1995-2026.xlsx`, лист 10 |
| ИПЦ России | BIS | `WS_LONG_CPI`, `M.RU.628` |
| Ключевая ставка | BIS | `WS_CBPOL`, `M.RU` |
| Курс USD/RUB | FRED | `CCUSMA02RUM618N` |
| ИПЦ США, ставка ФРС | FRED | `CPIAUCSL`, `FEDFUNDS` |

`data/russia_q.csv` собран скриптом `data/build_data.py` 18.11.2026 и лежит в репозитории:
I кв. 2011 – II кв. 2026, 62 квартала. Месячные ряды усреднены по кварталам. ИПЦ США за октябрь
2025 г. не публиковался, пропуск заполнен линейной интерполяцией.

## Требования

Python ≥ 3.10: numpy, pandas, scipy, statsmodels, matplotlib, openpyxl (только для сборки данных).
Случайности в расчётах нет.

## Код

| Файл | Что делает |
|---|---|
| `data/build_data.py` | скачивает ряды и собирает `data/russia_q.csv` |
| `py/qpm.py` | уравнения модели, калибровка, решение, импульсные отклики, гэпы |
| `index.qmd` | вызывает функции из `py/qpm.py` и строит страницу |

## Как воспроизвести

1. `cd projects/qpm-russia && python data/build_data.py` (необязательно: CSV уже в репозитории)
2. `quarto render projects/qpm-russia/index.qmd`

## Допущения

Цель по инфляции 4%, нейтральная реальная ставка 3% (`TARGET`, `R_NEUTRAL` в `py/qpm.py`).
Гэпы выпуска и реального курса — HP-фильтр, λ = 1600.
