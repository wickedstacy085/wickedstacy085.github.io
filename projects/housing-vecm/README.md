# README: «Цены на жильё в Германии: коинтеграционный анализ и прогноз» (Анастасия Смирнова)

## Обзор

Код повторяет исходный расчёт проекта на открытых квартальных данных Eurostat и ЕЦБ
за IV кв. 2005 – III кв. 2023 годов. Один файл, `index.qmd`, строит все 5 таблиц и 4 рисунка
страницы https://wickedstacy085.github.io/projects/housing-vecm/. 

## Данные

Все ряды публичные, источники и коды рядов — в [`data/README.md`](data/README.md).
Файл `data/housing.csv` лежит в репозитории. Исходные данные
(месячные, 12 рядов) не сохранились.

| Файл | Источник | Есть в репозитории |
|---|---|---|
| `data/housing.csv` | Eurostat (`prc_hpi_q`, `une_rt_m`, `namq_10_gdp`, `prc_hicp_midx`, `sts_copi_q`), ЕЦБ MIR | да |

## Требования

- R ≥ 4.3; пакеты: vars, urca, forecast, readr, dplyr, purrr, tibble, knitr, rmarkdown.
  Версии последней сборки печатаются в конце страницы проекта.
- Quarto ≥ 1.4.
- Случайность: только бутстрэп-интервалы IRF (рис. 2, 200 повторений).

## Код

| Файл | Что делает |
|---|---|
| `R/01_data.R` | загрузка `housing.csv` в объект `ts` |
| `R/02_stationarity.R` | тесты ADF и KPSS для уровней и разностей |
| `R/03_models.R` | VAR, тест Йохансена, VECM |
| `R/04_evaluation.R` | отложенная выборка и скользящая проверка прогнозов |
| `index.qmd` | вызывает функции из `R/` и строит страницу |

## Как воспроизвести

1. `git clone https://github.com/wickedstacy085/wickedstacy085.github.io`
2. Установить пакеты из списка выше.
3. `quarto render projects/housing-vecm/index.qmd`

## Таблицы и рисунки

| Результат | Чанк в `index.qmd` |
|---|---|
| Рис. 1, цены и безработица | `fig-data` |
| Табл. 1, тесты единичного корня | `tbl-unit-root` |
| Рис. 2, IRF на шок ставки | `fig-irf` |
| Табл. 2, Йохансен: цены и безработица | `tbl-johansen` |
| Табл. 3, Йохансен: цены, безработица, ставка | `tbl-johansen3` |
| Табл. 4 и рис. 3, отложенная выборка | `tbl-holdout`, `fig-holdout` |
| Табл. 5 и рис. 4, скользящая проверка | `tbl-rolling`, `fig-rolling` |

Все числа в тексте страницы вычисляются в чанке `setup`.
