ARIMA → VAR → VECM на 12 макрорядах за 2005–2023. Долгосрочная связь цен на жильё с рынком труда и честная оценка прогноза на отложенной выборке.
Дата публикации

1 июня 2025 г.

Выпускная квалификационная работа, НИУ ВШЭ · 2025 · R · код на GitHub

Главное. Цены на жильё в Германии связаны с безработицей устойчивым долгосрочным равновесием (тест Йохансена: trace = 28,6 при критическом 19,96). VECM, учитывающая эту связь, снижает ошибку прогноза на горизонте 24 месяцев на ⟨X⟩% относительно наивного прогноза.

Вопрос

Какие макрофакторы определяют динамику цен на жильё в долгосрочном и краткосрочном периоде и какая модель даёт лучший прогноз на два года вперёд?

Данные

12 месячных рядов, октябрь 2005 – октябрь 2023 (217 наблюдений): индекс цен на жильё, безработица, ВВП, население, инфляция, ставки (ключевая и ипотечная), курс евро, располагаемый доход, аренда, стоимость строительства. Источник: ⟨…⟩, описание в data/README.md.

Код 
source("R/01_data.R"); source("R/02_stationarity.R")
source("R/03_models.R"); source("R/04_evaluation.R")
y_all <- load_housing("data/housing.csv")

Шаг 1. Свойства рядов

Ряды нестационарны в уровнях, поэтому МНК на уровнях дал бы ложную регрессию. ADF и KPSS проверяют гипотезы с противоположными нулями: вывод о порядке интеграции делается, только когда тесты согласуются.

Шаг 2. Бенчмарки: ARIMA и VAR

ARIMA задаёт нижнюю планку точности. VAR показывает краткосрочную динамику через функции импульсного отклика. Порядок Холецкого идёт от медленных переменных к быстрым: ⟨население → ВВП → безработица → ставки → цены на жильё⟩.

Код 
y_core <- y_all[, c("Unemployment", "MRate", "DPI", "Construction", "Index")]
m_var  <- fit_var(diff(y_core))
plot(irf(m_var, impulse = "Unemployment", response = "Index", n.ahead = 24, boot = TRUE))

Шаг 3. Коинтеграция и VECM

VAR в разностях теряет информацию о долгосрочном равновесии, поэтому проверяется коинтеграция.

Код 
y2   <- y_all[, c("Index", "Unemployment")]
vecm <- fit_vecm(y2)
summary(vecm$johansen)
Гипотеза Trace Крит. 5% Вывод
r ≤ 0 28,58 19,96 отвергается: связь есть
r ≤ 1 1,07 9,24 не отвергается: связь одна

Нормированный коинтеграционный вектор: Index + 119,03·Unemployment − 911,12 ~ I(0). В равновесии рост безработицы на 1 п.п. соответствует снижению индекса цен примерно на 119 пунктов. Скорость корректировки α = ⟨…⟩: половина отклонения закрывается за ⟨…⟩ мес.

Код 
coef(vecm$ecm$rlm)["ect1", ]
half_life(coef(vecm$ecm$rlm)["ect1", "Index.d"])

Диагностика остатков: автокорреляции нет (Portmanteau), ARCH-эффектов нет. Нормальность отвергается (Jarque–Bera) из-за тяжёлых хвостов, поэтому интервалы строятся бутстрэпом.

Шаг 4. Насколько хорош прогноз

Модели оценены на данных до октября 2021 года, прогноз сравнивается с фактом за ноябрь 2021 – октябрь 2023.

Код 
p <- attr(res, "paths")
matplot(p$time, p[, -1], type = "l", lty = 1, lwd = 2,
        col = c("black", "grey60", "steelblue", "firebrick"), xlab = "", ylab = "Index")
legend("topleft", c("Факт", "Random walk", "ARIMA", "VECM"), lwd = 2, bty = "n",
       col = c("black", "grey60", "steelblue", "firebrick"))
