# Данные

`housing.csv` — месячные ряды, 2005-10 … 2023-10. Колонки:

| колонка | показатель | ед. | источник |
|---|---|---|---|
| date | первое число месяца | — | — |
| Index | индекс цен на жильё | индекс | ⟨Eurostat / нац. стат⟩ |
| Unemployment | уровень безработицы, SA | % | ⟨…⟩ |
| GDP | ВВП, SA | млн EUR | ⟨…⟩ |
| Population | население | чел. | ⟨…⟩ |
| Inflation | инфляция | % | ⟨…⟩ |
| Rate | процентная ставка | % | ⟨…⟩ |
| EUR | курс евро | ⟨…⟩ | ⟨…⟩ |
| DPI | располагаемый доход | млрд EUR | ⟨…⟩ |
| MRate | ставка по ипотеке | % | ⟨…⟩ |
| Rent | средняя аренда | EUR/м² | ⟨…⟩ |
| Construction | индекс стоимости строительства | индекс | ⟨…⟩ |

Если лицензия источника не позволяет публиковать данные, оставьте только этот README
и скрипт загрузки.
