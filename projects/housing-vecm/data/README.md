# Данные

`housing.csv` — квартальные ряды по Германии, IV кв. 2005 – III кв. 2023 (72 наблюдения),
собраны из открытых источников 18.11.2026. Месячные ряды усреднены по кварталам.

| колонка | показатель | ед. | источник |
|---|---|---|---|
| date | начало квартала | — | — |
| Index | индекс цен на жильё, все покупки | 2015 = 100, NSA | Eurostat `prc_hpi_q` (purchase=TOTAL, unit=I15_Q) |
| Unemployment | уровень безработицы, 15–74 | %, SA | Eurostat `une_rt_m` |
| MRate | ставка по новым ипотечным кредитам домохозяйствам | % годовых | ЕЦБ MIR `M.DE.B.A2C.A.R.A.2250.EUR.N` |
| GDP | ВВП в ценах 2010 г. | млн EUR, SCA | Eurostat `namq_10_gdp` (B1GQ, CLV10_MEUR) |
| HICP | гармонизированный индекс потребительских цен | 2015 = 100 | Eurostat `prc_hicp_midx` (CP00) |
| Construction | стоимость строительства жилых зданий | 2015 = 100, NSA | Eurostat `sts_copi_q` (indic_bt=COST) |

В ВКР использовались месячные данные из других источников, исходный файл не сохранился.
Поэтому оценки здесь отличаются от дипломных: это независимое воспроизведение расчёта.
